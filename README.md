# OOP Library System

A Java console application that simulates a simple library lending system.

## Features

- Add books, magazines, and DVDs
- Register library members
- Borrow and return library items
- Display the complete library catalog
- Track borrowed items
- Generate a library report
- Validate user input
- Handle library errors using custom exceptions

## OOP Concepts Used

- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
- Method overriding
- Constructors
- Static members
- Exception handling

## Collections Used

- Map for storing library items
- Map for storing members
- Set for tracking borrowed item IDs
- List for storing each member's borrowed items

## How to Run

1. Open the project in IntelliJ IDEA.
2. Run the `Main` class.
3. Select an option from the displayed menu.
